! 为什么需要本独立研发驱动？

富士施乐（Fuji Xerox）中小型商用复合机（如 DocuCentre S2110 / S2011 / S2320 / S2520 等）出厂采用主机端压缩打印语言 HBPL。由于厂商未向 Mac 平台提供对应免卡驱动，且出厂未标配昂贵的 PostScript 芯片，导致在 Mac 上直接使用通用驱动会出现：

  • 狂吐废纸：打印机连续吐出带有 %!PS-Adobe-3.0 等代码的乱码废纸。
  • 文字发灰有锯齿：macOS 系统自带通用 PCL 锁死在 300 DPI 粗糙点阵抖动，文字毛刺发灰严重。
  • 本驱动解决方案：由作者独立全手工编写的 macOS 原生专用高性能 CUPS 打印滤镜与驱动套件（纯 C 语言机器码打造，适配 Apple Silicon M系列与 Intel 双架构）。直连打印机底层输出 600 DPI 纯正矢量黑白 HBPL 硬件控制流，字迹锐利纯黑，出纸稳定顺畅，彻底让 Mac 摆脱官方硬件扩展卡的昂贵束缚！

1 方式一：使用图形向导 App 激活与安装（推荐）

  1. 双击打开下载的 FujiXerox_DocuCentre_S2110_Mac_Driver.dmg 镜像。
  2. 双击运行 「富士施乐打印机一键配置向导.app」。
  3. 一机一码安全激活：
    • 首次运行时，向导已自动将您 Mac 的主板硬件识别代码复制到剪贴板。
    • 将代码发送给作者获取专属 7 天时效激活密钥（格式：XXXX-XXXX-XXXX），输入密钥点击“验证激活”。
    • 验证成功后，系统自动绑定该机永久授权，无需重复激活。
  4. 选择连接方式：
    • 网络打印 (TCP/IP)：输入复合机局域网 IP（例如 192.168.1.200），向导将严格校验 IPv4 格式。
    • USB 直连：插上 USB 数据线，向导会自动识别并绑定设备。
  5. 弹出系统提权提示时，输入 Mac 管理员开机密码或轻触 Touch ID 允许。
  6. 提示“配置成功”后即可在任意软件中按 Cmd + P 正常打印！

2 方式二：双击终端脚本安装

如果您习惯终端操作，或在批量维护分发环境下：

  1. 打开 DMG 镜像，直接双击运行 双击安装驱动.command。
  2. 终端将自动引导选择连接类型与输入 IP 地址，并完成系统 CUPS 队列注册。

4 驱动卸载方法

如需从系统中彻底移除该驱动：

  • 在 DMG 中双击运行 「卸载驱动.app」；
  • 或双击运行 双击卸载驱动.command，即可一键清理打印队列与系统驱动文件。
💡 打印排障小贴士： 若打印机没有反应，请检查打印机屏幕是否显示“离线”或“缺纸”，并在“系统设置 -> 打印机与扫描仪”中确认打印队列状态是否为“空闲”。如果打印机 IP 地址变更，重新运行配置向导输入新 IP 即可。

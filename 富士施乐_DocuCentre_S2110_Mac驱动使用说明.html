! 为什么需要本驱动？

富士施乐（Fuji Xerox）中小型商用复合机（如 DocuCentre S2110 / S2011 / S2320 / S2520 等）出厂采用主机端压缩打印语言 HBPL。官方未标配昂贵的 PostScript 芯片，导致在 Mac 上直接使用通用驱动会出现：

  • 狂吐废纸：打印机连续吐出带有 %!PS-Adobe-3.0 或代码乱码的多张废纸。
  • 文字发灰有锯齿：macOS 内置通用 PCL 锁死在 300 DPI 点阵抖动，文字毛刺严重。
  • 本驱动解决方案：逆向原厂 Windows 通信协议，打造专供 macOS 的 CUPS 滤镜，直接输出纯正的 600 DPI HBPL 二进制流，字迹锐利纯黑，出纸顺畅。

1 方式一：使用图形向导 App 安装（推荐）

  1. 双击打开下载的 FujiXerox_DocuCentre_S2110_Mac_Driver.dmg 镜像。
  2. 双击运行 「富士施乐打印机一键配置向导.app」。
  3. 根据向导提示选择连接方式：
    • 网络打印 (TCP/IP)：输入打印机的局域网 IP（例如 192.168.1.200），向导将严格校验 IPv4 格式。
    • USB 直连：插上 USB 数据线，向导会自动识别并绑定设备。
  4. 弹出系统提权提示时，输入 Mac 管理员开机密码或轻触 Touch ID 允许。
  5. 提示“配置成功”后即可在任意软件中按 Cmd + P 正常打印！

2 方式二：双击终端脚本安装

如果您习惯终端操作，或在无界面批量分发环境下：

  1. 打开 DMG 镜像，直接双击运行 双击安装驱动.command。
  2. 终端将自动引导选择连接类型与输入 IP 地址，并完成系统 CUPS 队列注册。

3 驱动核心特性与选项设置

⚡ 600 DPI 矢量级高清解析 点对点纯黑锐利字体，消灭发灰与毛刺锯齿。
📄 丰富纸张尺寸支持 原生支持 A3、A4、A5、B4、B5、8K、16K、Letter、Legal。
🔄 原生双面打印 (Duplex) 支持单面、长边翻转双面与短边翻转双面，装订轻松自如。
📥 多纸盒进纸管理 支持自动选择、第一纸盒、第二纸盒（选配）及旁路手送托盘。

4 驱动卸载方法

如需从系统中彻底移除该驱动：

  • 在 DMG 中双击运行 「卸载驱动.app」；
  • 或双击运行 双击卸载驱动.command，即可一键清理打印队列与系统驱动文件。
💡 打印排障小贴士： 若打印机没有反应，请检查打印机屏幕是否显示“离线”或“缺纸”，并在“系统设置 -> 打印机与扫描仪”中确认打印队列状态是否为“空闲”。如果打印机 IP 地址变更，重新运行配置向导输入新 IP 即可。

# 富士施乐 (Fuji Xerox) DocuCentre S2110 / S2011 macOS 专用驱动

本驱动由作者独立自主研发，专为 macOS 用户打造，免去购置昂贵的 PostScript (PS) 硬件扩展卡。支持局域网网络打印与 USB 直连、600 DPI 矢量级高清解析、原生双面打印与多纸盒进纸管理。

---

## 适配机型与硬件支持

* **适用系列**：Fuji Xerox DocuCentre S2110 / S2011 / S2320 / S2520 等
* **硬件接口**：USB 本地直连（VID 0x0550, PID 0x01BE）及 TCP/IP 网络打印（Socket 9100 端口）
* **解析度**：锁定硬件 600 x 600 DPI 纯正黑白矢量打印
* **操作系统**：全面支持 macOS 10.15 (Catalina) 至 macOS 15 (Sequoia)
* **芯片架构**：原生双架构 Universal Binary（原生支持 Apple Silicon M1/M2/M3/M4 系列芯片及 Intel x86_64 处理器）

## 安装与配置步骤

### 方法一：图形向导 App 安装（推荐）
1. 双击打开镜像中的 **「富士施乐打印机一键配置向导.app」**；
2. 首次运行时，向导已**自动将您 Mac 的设备识别代码复制到剪贴板**，将代码发送给客服获取专属激活密钥并输入；
3. 根据提示选择连接方式：
   * **网络打印**：输入复印机的局域网 IP 地址（例如 `192.168.1.200`）；
   * **USB 直连**：连接 USB 数据线，向导将自动识别并绑定；
4. 弹出系统授权提示时，输入 Mac 管理员开机密码或使用 Touch ID 指纹确认；
5. 提示“配置成功”后，即可在任意软件中直接按 `Cmd + P` 发送打印任务。

### 方法二：终端一键安装
1. 打开 DMG 磁盘镜像；
2. 双击运行 **`双击安装驱动.command`**，按屏幕提示操作即可完成配置。

---

## 卸载方法

如需从系统中彻底移除该打印机与驱动文件：
* 双击运行 DMG 内的 **「卸载驱动.app」**；
* 或双击运行 **`双击卸载驱动.command`** 即可一键清理打印队列与系统驱动文件。

---

## 打印排障小贴士

1. **状态检查**：若打印无响应，请在“系统设置 -> 打印机与扫描仪”中查看打印机队列是否处于“空闲”状态。
2. **网络变更**：若复印机的局域网 IP 发生变动，只需重新打开向导 App 输入新 IP 即可，无需重复授权。

# 富士施乐 (Fuji Xerox) DocuCentre S2110 / S2011 macOS 专用驱动 (DMG 安装包)

本驱动专为 macOS 用户打造，免去购置昂贵的 PostScript 硬件扩展卡，支持网络打印与 USB 直连、600 DPI 矢量级高清解析、原生双面打印与多纸盒控制。

---

## 适配机型

* **Fuji Xerox DocuCentre S2110**
* **Fuji Xerox DocuCentre S2011**
* **Fuji Xerox DocuCentre S2320**
* **Fuji Xerox DocuCentre S2520**
* 打印语言：HBPL (Host Based Print Language)
* USB 硬件标识：VID 0x0550, PID 0x01BE

---

## 操作系统兼容性

* **macOS 15 (Sequoia)**
* **macOS 14 (Sonoma)**
* **macOS 13 (Ventura)**
* **macOS 12 (Monterey)**
* **macOS 11 (Big Sur)**
* **macOS 10.15 (Catalina)**
* 架构支持：**Apple Silicon (M1 / M2 / M3 / M4)** 与 **Intel (x86_64)** 双架构 Universal Binary

## 安装方法

### 方法一：图形向导 App 安装（推荐）
1. 双击挂载 `FujiXerox_DocuCentre_S2110_Mac_Driver.dmg`。
2. 双击打开 **「富士施乐打印机一键配置向导.app」**。
3. 选择连接方式（网络打印或 USB 直连），网络打印请输入打印机局域网 IP（如 `192.168.1.200`）。
4. 弹出提权提示时输入 Mac 开机密码或使用 Touch ID。
5. 提示配置成功后即可直接按 `Cmd + P` 打印。

### 方法二：终端一键安装
1. 打开 DMG 磁盘镜像。
2. 双击运行 **`双击安装驱动.command`**，按屏幕提示输入 IP 即可。

---

## 卸载方法

* 双击运行 DMG 内的 **「卸载驱动.app」** 或 **`双击卸载驱动.command`** 即可彻底清除打印队列与驱动组件。
